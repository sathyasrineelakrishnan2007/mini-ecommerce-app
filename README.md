
# Mini E-Commerce App

## Project Overview
A beginner-friendly e-commerce web application built using HTML, CSS, and JavaScript. Users can explore products, add items to their cart, update quantities, calculate the total price, and preview checkout.

## Key Features
- Dynamic product rendering using JavaScript objects
- Add products to the shopping cart
- Increase and decrease product quantities
- Automatic cart count and total price calculation
- Checkout modal preview
- Responsive design for mobile and desktop
- Interactive buttons and hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add products to the cart and test checkout.

## Project Structure
- `index.html` - Webpage structure
- `style.css` - Styling and responsive design
- `script.js` - Product, cart, and checkout functionality

## Expected Outcome
Learn dynamic rendering, JavaScript objects and arrays, event handling, cart calculations, and modal interactions.
